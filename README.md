# Raghul D. — Premium Engineering Placement Portfolio

A responsive, static portfolio website with a premium navy / electric blue-violet theme. It uses HTML, CSS, and vanilla JavaScript, so no build tools are required.

## Open it on a computer
1. Extract the ZIP file.
2. Open the `raghul_portfolio` folder.
3. Double-click `index.html` to preview it in your browser.

## Open it on Android
1. Download and extract the ZIP using your file manager or an archive app.
2. Open the extracted `raghul_portfolio` folder.
3. Open `index.html` with an HTML preview app or a code editor that offers browser preview. Some Android file managers do not open local HTML files correctly; if so, use a laptop or publish the site using GitHub Pages.

## Personalize before sharing with recruiters
- Add your portrait as `assets/profile.jpg` (JPG format works best). The image is automatically shown in the profile frame.
- Replace the college name, engineering branch, and expected graduation year in `index.html`.
- Replace `your.email@example.com` with your real professional email.
- Update the GitHub and LinkedIn links with your profiles.
- Add your actual resume as `assets/Raghul-Resume.pdf`, then update the resume button in `index.html` to link to that file.
- Build and test the listed starter projects before changing their status from **Planned** or claiming them as completed.

## Publish free with GitHub Pages
1. Sign in at https://github.com/ and create a new public repository, for example `raghul-portfolio`.
2. Upload the contents inside the `raghul_portfolio` folder (the `index.html`, `style.css`, `script.js`, and `assets` folder) to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.

## Files
